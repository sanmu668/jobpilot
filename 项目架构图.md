# 🔄 二、核心业务流程图（用户视角）

👉 这是最重要的一张（直接对应用户体验）

```
用户进入首页
      ↓
上传简历（PDF/Word）
      ↓
简历解析（Resume Service）
      ↓
调用AI解析（Python服务）
      ↓
返回结构化数据（skills/experience）
      ↓
输入岗位JD
      ↓
JD解析（Job Service + AI）
      ↓
匹配分析（Match Service）
      ↓
基础评分（本地算法）
      ↓
AI深度分析（差距/建议）
      ↓
返回前端展示
      ↓
用户点击「优化简历」
      ↓
AI优化生成新版本
      ↓
保存 Resume Version
      ↓
推荐岗位（推荐系统）
```

# ⚡ 四、技术架构分层图（工程级）

```
【前端层】
Vue3 + Vite + Pinia + Echarts

        ↓

【网关层】
Spring Cloud Gateway
- JWT认证
- 限流
- 路由转发

        ↓

【业务层】
- User Service
- Resume Service
- Job Service
- Match Service
- Payment Service

        ↓

【AI能力层】
Python FastAPI
- NLP解析
- 匹配分析
- 文本优化

        ↓

【数据层】
MySQL（结构化数据）
Redis（缓存）
Elasticsearch（搜索/推荐）

        ↓

【外部服务】
OpenAI API
支付接口（支付宝/Stripe）
```
