# 数据库设计

# 一、核心ER关系图（逻辑）

```
User（用户）
  │
  ├── Resume（简历）
  │        └── ResumeVersion（版本）
  │
  ├── Job（岗位JD）
  │
  ├── MatchRecord（匹配记录）
  │        ├── Resume
  │        └── Job
  │
  ├── OptimizeRecord（优化记录）
  │  
  ├── UsageRecord（调用记录）
  │
  └── Subscription（订阅/VIP）
```

------

# 二、数据库表设计（字段级）

------

# 1️⃣ 用户模块

## 表：user

```
CREATE TABLE user (
    id BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '用户ID',
    
    email VARCHAR(100) UNIQUE COMMENT '邮箱',
    password VARCHAR(255) COMMENT '密码',
    username VARCHAR(50) COMMENT '昵称',
    avatar_url VARCHAR(255) COMMENT '头像URL',
    
    role VARCHAR(20) DEFAULT 'user' COMMENT '角色：admin / user',
    
    vip_level INT DEFAULT 0 COMMENT 'VIP等级：0免费 1VIP 2企业',
    vip_expire_time DATETIME COMMENT 'VIP过期时间',
   
    status TINYINT DEFAULT 1 COMMENT '状态：1正常 0禁用',
    
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```

------

## 表：subscription（订阅记录）

```
CREATE TABLE subscription (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT,
    
    plan_type VARCHAR(20),     -- monthly / yearly
    price DECIMAL(10,2),
    
    start_time DATETIME,
    end_time DATETIME,
    
    status TINYINT,            -- 1有效 0过期
    
    created_at DATETIME
);
```

------

# 2️⃣ 简历模块

------

## 表：resume

```
CREATE TABLE resume (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT,
    
    title VARCHAR(100),
    file_url VARCHAR(255),
    
    raw_content LONGTEXT,          -- 原始文本
    parsed_json JSON,              -- AI解析结果
    
    status TINYINT DEFAULT 1,
    
    created_at DATETIME,
    updated_at DATETIME
);
```

------

## 表：resume_version（关键设计）

👉 支持“多版本优化”

```
CREATE TABLE resume_version (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    resume_id BIGINT,
    
    version_no INT,
    content LONGTEXT,
    optimized_content LONGTEXT,
    
    ai_suggestions JSON,
    
    created_at DATETIME
);
```

------

## 表：resume_skill（可扩展）

```
CREATE TABLE resume_skill (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    resume_id BIGINT,
    
    skill_name VARCHAR(100),
    skill_level INT,      -- 1-5
    
    created_at DATETIME
);
```

# 4️⃣ 匹配分析模块（核心）

------

```
CREATE TABLE match_record (
```

# 三、关键设计说明（非常重要）

------

## ⭐ 1. 为什么用 JSON 字段？

👉 因为：

- AI输出结构不稳定
- 方便扩展
- 避免频繁改表

------

## ⭐ 2. 为什么要 resume_version？

👉 核心价值：

```
用户会不断优化简历（这是留存关键）
```

------

## ⭐ 3. 为什么 match_record 独立？

👉 因为：

- 可缓存结果
- 支持历史对比
- 可用于推荐算法

------

## ⭐ 4. usage_record 必须有

👉 否则：

- 无法做免费限制
- 无法商业化

------

## ⭐ 5. ai_call_log 是成本控制核心

👉 你未来一定会踩坑：

- Token爆炸
- 成本不可控

------

# 四、索引设计（性能关键）

------

## 必加索引：

```
CREATE INDEX idx_user_id ON resume(user_id);
CREATE INDEX idx_resume_id ON match_record(resume_id);
CREATE INDEX idx_job_id ON match_record(job_id);
CREATE INDEX idx_created_at ON usage_record(created_at);
```
