# 📘 产品方案文档（完整版）

# 一、产品概述

## 1.1 产品名称

**JobPilot AI —— 智能简历与岗位匹配分析平台**

------

## 1.2 产品定位

> 🎯 一个AI驱动的“求职决策系统”，而不是简单的匹配工具

核心能力：

- 简历解析
- 岗位理解
- 匹配分析
- 优化建议
- 求职路径规划

------

## 1.3 目标用户

### 👨‍🎓 C端用户

- 应届毕业生
- 1-5年经验求职者
- 转行人群

### 🏢 B端（后期）

- HR招聘人员
- 猎头公司

------

## 1.4 核心价值

```
传统工具：告诉你匹配度
本产品：告诉你如何拿到Offer
```

------

# 二、核心功能模块

------

## 2.1 简历管理模块

### 功能点：

- 上传简历（PDF / Word）
- 在线编辑简历
- 简历版本管理
- 简历结构化解析

### AI能力：

- 自动提取：
	- 技能标签
	- 项目经验
	- 工作经历
	- 教育背景

------

## 2.2 岗位JD管理模块

### 功能点：

- 粘贴JD
- URL解析（招聘网站）
- JD结构化分析

### 输出结构：

```
{
  "skills_required": [],
  "skills_preferred": [],
  "experience": "",
  "education": "",
  "keywords": []
}
```

------

## 2.3 匹配分析模块（核心）

### 功能点：

- 总匹配度评分（0-100）
- 多维度评分：
	- 技能匹配
	- 项目匹配
	- 经验匹配
	- 教育匹配

------

### 输出示例：

```
{
  "total_score": 82,
  "skill_match": 90,
  "experience_match": 75,
  "project_match": 80
}
```

------

## 2.4 差距分析模块

### 功能点：

- 缺失技能识别
- 经验不足分析
- 简历表达问题分析

------

### 示例：

```
缺少技能：Docker、Kubernetes
项目经验不足：微服务架构
表达问题：缺乏量化指标
```

------

## 2.5 AI简历优化模块（核心卖点）

### 功能点：

- bullet point优化
- STAR法则重写
- 关键词增强（ATS优化）

------

### 示例：

原句：

```
参与系统开发
```

优化后：

```
负责设计并实现高并发订单系统，提升系统吞吐量30%
```

------

## 2.6 岗位推荐模块

### 功能点：

- 基于简历推荐岗位
- 支持筛选（城市 / 薪资 / 技术栈）

------

## 2.7 求职策略模块（差异化）

### 输出：

- 是否建议投递
- 优先级排序
- 提升路径

------

### 示例：

```
建议优先投递中型互联网公司Java岗位，
当前匹配度82%，补充Redis与微服务经验后可达90%+
```

------

## 2.8 模拟面试模块（后期）

- AI提问
- 回答评分
- 优化建议

------

# 四、AI设计方案（关键）

------

## 4.1 Prompt设计原则

- 结构化输出（JSON）
- 限制token
- 可解释性强

------

## 4.2 示例Prompt（简历优化）

```
你是一个资深HR，请优化以下简历内容：
要求：
1. 使用STAR法则
2. 增加量化成果
3. 提高专业性
输出JSON格式
```

------

## 4.3 成本控制策略

- 缓存分析结果（Redis）
- 限制免费调用次数
- 分段调用（减少token）

------
