# 开发计划

# 📅 一、整体开发策略（先说清路线）

先说一个关键判断：
👉 如果你一开始就按“完整微服务+全功能”做，大概率**拖慢进度甚至做不完**

### ✅ 正确策略：

```
Phase 1：MVP（单体 + 核心功能）
Phase 2：增强功能（AI优化 + 推荐）
Phase 3：微服务拆分 + 商业化
Phase 4：高级功能（面试/企业版）
```

------

# 🧭 二、整体周期规划（推荐 8~10周）

| 阶段    | 时间 | 目标          |
| ------- | ---- | ------------- |
| Phase 1 | 2周  | MVP上线       |
| Phase 2 | 2周  | AI增强        |
| Phase 3 | 2周  | 推荐 + VIP    |
| Phase 4 | 2周  | 微服务拆分    |
| Phase 5 | 持续 | 优化 + 商业化 |

------

# 🚀 三、Phase 1（MVP版本，必须完成）

## 🎯 目标

```
用户可以：
上传简历 → 输入JD → 得到匹配结果
```

------

## 📦 功能范围（严格控制）

### 必做：

- 用户登录
- 简历上传 + 解析
- JD解析
- 匹配评分（基础算法）
- 分析结果展示

### ❌ 不做：

- AI优化
- 推荐
- VIP

------

## 🗓️ Sprint拆分（2周）

------

### 🔹 Week 1：基础架构 + 数据流

#### 后端：

- 搭建SpringBoot项目（单体）
- 数据库建表（你刚设计的那套）
- 完成：
	- user模块
	- resume模块（上传+解析）

#### 前端：

- Vue3项目初始化
- 登录页 + 首页
- 上传页面

#### AI：

- Python FastAPI搭建
- 简历解析API（初版）

------

### 🔹 Week 2：核心功能打通

#### 后端：

- JD解析
- 匹配分析（简单算法）
- API接口完成

#### 前端：

- 分析结果页（核心）
- 数据展示（图表）

#### AI：

- JD解析
- 差距分析（初版）

------

## ✅ MVP验收标准

```
✔ 上传简历成功
✔ 输入JD成功
✔ 返回匹配分数
✔ 页面可展示
```

------

# 🔥 四、Phase 2（AI增强版本）

## 🎯 目标

让产品“有价值”，而不是玩具

------

## 新增功能

- AI差距分析（增强版）
- AI简历优化
- 简历版本管理

------

## 🗓️ Sprint（2周）

------

### Week 3

- 接入OpenAI API
- Prompt工程（优化建议）
- 优化模块开发

------

### Week 4

- 前端优化页（左右对比）
- Resume Version实现
- AI结果缓存（Redis）

------

## ✅ 验收标准

```
✔ AI能生成高质量优化建议
✔ 用户能看到优化前后对比
✔ 可保存版本
```

------
