# 项目文件结构

# 一、后端项目结构（SpringCloud 微服务）

------

## 🧱 总体结构（多模块）

```
jobpilot-backend/
│
├── gateway-service/           # 网关（统一入口）
├── user-service/              # 用户服务
├── resume-service/            # 简历服务
├── job-service/               # 岗位服务
├── match-service/             # 匹配分析服务
├── ai-service-client/         # AI调用封装
├── payment-service/           # 支付/VIP
│
├── common/                    # 公共模块
│   ├── common-core/
│   ├── common-utils/
│   ├── common-entity/
│   ├── common-exception/
│   └── common-config/
│
├── pom.xml
```

------

## 🔥 核心服务职责划分（很关键）

| 服务              | 职责             |
| ----------------- | ---------------- |
| gateway           | 路由、鉴权、限流 |
| user-service      | 用户/VIP         |
| resume-service    | 简历解析、管理   |
| job-service       | JD管理           |
| match-service     | 匹配计算         |
| ai-service-client | 调Python AI      |
| payment-service   | 支付             |

------

## 🧠 AI调用设计（重点）

```
match-service
     ↓
ai-service-client（Feign）
     ↓
Python FastAPI
```

👉 不要在业务服务里直接调AI（这是很多人会踩的坑）

------

## 🔌 Feign接口示例

```
@FeignClient(name = "ai-service")
public interface AiClient {

    @PostMapping("/ai/match")
    MatchResult analyze(@RequestBody MatchRequest request);
}
```

## 🧠 OpenAI封装

```
def call_openai(prompt):
    response = client.chat.completions.create(
        model="gpt-4o-mini",
        messages=[{"role": "user", "content": prompt}]
    )
    return response
```

## 📡 API示例
